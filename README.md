# 反诈局中局：你的手机

面向大学生的竖屏 H5 反诈互动游戏。**产品形态：整个网页模拟一部可自由探索的虚构手机**；手机端直接铺满可见网页，开场、桌面、消息、钱包、结局及复盘都在手机内进行。玩家可以随时切换应用、查看余额和手册，再返回当前剧情，不强制困在对话中；电脑端居中预览同一画面。

当前状态：**第一关「刷单返利」可玩 MVP 已实现**（Vue 3 + Vite + TypeScript）。剧情引擎、整页手机界面、按经历复盘与版本化存档均已完成，单元/集成测试与真实浏览器验证全部通过。第二关、账号、后端、排行榜均未开发。

## 交给开发模型时怎么做

将此仓库作为其工作目录，直接给出以下指令：

> 阅读 `AGENTS.md`、`LEVEL-01.md`、`DEVELOPMENT.md`、`SCENES.md` 和 `ACCEPTANCE.md`，在仓库根目录实现 Vue 3 + Vite + TypeScript 可玩 H5。整个网页必须呈现为一部可操作的虚构手机：手机端铺满可见区域，先进入桌面，点通知/消息图标可进群，玩家也可随时切到钱包/手册/其他可用区域并返回当前剧情；离开待付款页只暂停、不自动扣款或取消，结局与复盘也在手机内可离开再进入；不要做成网页中嵌一个缩小手机模型或普通答题页。先完成全部分支与手机交互，再打磨视觉；完成后运行构建和可用测试，更新本 README 中的真实启动命令、已实现功能与已知限制，逐条报告验收情况。不要开发第二关或联机服务。

## 首版目标

一条完整、约 2–3 分钟的「刷单返利」剧情：虚构手机 → 兼职群 → 100 元模拟垫付 → 130 元平台展示返款 → 300 元解冻费诱导 → 不同结局 → 按玩家经历复盘 → 重开。所有金额仅为游戏模拟；不接支付、不收集个人信息。

## 命令与运行方式

```bash
npm install          # 安装依赖
npm run dev          # 本地开发（http://127.0.0.1:5173/）
npm run build        # 生产构建，输出 dist/
npm run preview      # 预览构建产物（http://127.0.0.1:4173/）
npm run typecheck    # vue-tsc 类型检查
npm test             # 单元 + 集成测试（vitest）
npm run verify       # 真实浏览器（Edge/Chrome headless）端到端验证，产出截图与报告
npm run smoke:public -- <公网URL>   # 公网部署冒烟测试：真实浏览器打开公网地址，确认能玩
```

部署：`vite.config.ts` 使用 `base: './'` 相对路径，`dist/` 可直接放到任意静态目录（含子路径）。核心剧情不依赖任何外部服务。

### 临时发布到公网（隧道）

本项目是纯静态 H5、没有后端，所以任何静态托管都能用。临时演示最省事的做法是打一条隧道：

```bash
# 1) 起预览服务（对外监听，便于隧道回连）
node node_modules/vite/bin/vite.js preview --port 4173 --strictPort --host 0.0.0.0

# 2) 另开一个终端，把 4173 隧道到公网（cloudflared 需自行下载，不要放进仓库）
cloudflared tunnel --url http://127.0.0.1:4173 --no-autoupdate

# 3) 拿到形如 https://xxxx.trycloudflare.com 的地址后，做一次真实浏览器冒烟
npm run smoke:public -- https://xxxx.trycloudflare.com/
```

两个坑已经踩过并修好，重新部署时不必再踩：

1. **`403 Blocked request. This host "..." is not allowed.`**
   这不是 Cloudflare 拦的，是 Vite preview 自己的 Host 校验（防 DNS rebinding）。已在 `vite.config.ts` 的 `preview.allowedHosts` 放行 `.trycloudflare.com` 与 `.loca.lt`。只放行这两个隧道域名，本机与局域网访问照旧，陌生 Host 仍然返回 403（可实测验证）。
2. **`EPERM: unlink '...cloudflared.exe'`**
   `verify-edge.mjs` 原先会整目录删掉 `.verify/`，一旦里面放了对外的隧道程序（进程占用文件）就会直接把验证跑崩。现在只清理脚本自己产出的截图/profile/report。另外隧道程序属于本机工具，建议放在仓库外（例如 `E:\DSH\_fj-tunnel\`），不要放进工作区。

临时隧道地址的注意点：

- **开关都在本机，不进仓库**：关闭外网访问只要结束 `cloudflared` 进程（`Stop-Process -Name cloudflared -Force`），本地与局域网预览不受影响；关闭后公网地址返回 HTTP 530 属正常。关闭状态下 `preview.allowedHosts` 里的白名单不产生任何影响，因为没有任何进程在监听那个 Host。
- **地址是临时的**：cloudflared quick tunnel 每次重启都会换一个新域名，且官方明确不保证可用性（无账号隧道仅供试用）。
- **任何人拿到链接都能玩**：游戏不接后端、不上传玩家选择，除玩家本机 `localStorage` 外无数据落地。
- **延迟偏高**：实测出口落在 Cloudflare 圣何塞（sjc），单次资源请求约 1–1.7 秒；首屏可见约 5 秒。功能正常，但不如局域网地址流畅。局域网试玩仍推荐 `http://<本机IP>:4173/`。

## 工程结构

```text
src/
  app/AppShell.vue       # 全屏手机容器：状态栏 + 应用视口 + 底部导航 + 弹层
  app/navigation.ts      # UI 导航状态（应用/会话/待付款推导），不含剧情与金额
  app/clock.ts           # 北京时间时钟（固定 Asia/Shanghai，分钟对齐刷新）
  app/unlock.ts          # 上滑解锁判定（纯函数：位移、阈值、回弹）
  app/notifications.ts   # 通知队列（预警/消息两类，独立时长，自动关闭，手动关闭不竞态）
  app/settings.ts        # 版本化玩家设置（音效、顶部提醒开关）
  app/sound.ts           # Web Audio 合成音效（无音频文件，失败静默降级）
  app/useGame.ts         # 组合式封装：dispatch 是唯一写入口，负责存档
  data/antifraud.ts      # 「国家反诈中心提醒您」各节点提醒文案
  game/types.ts          # 节点、选项、状态、效果类型
  game/engine.ts         # choose() 事务式转移、不变式校验、结局视图
  game/debrief.ts        # 按 riskTags 生成复盘 + 肯定式误导表述检查
  game/storage.ts        # 版本化 localStorage，校验失败安全回退
  data/level01.ts        # 第一关节点、转移表、消息、话术标注、通用手册
  scenes/                # Intro / Home / Chat / Wallet / Manual / Ending / Review / PlainApp
  components/            # 状态栏、底部导航、应用标题栏、弹层、气泡、模拟声明
  styles/                # 设计令牌与基础样式（含 prefers-reduced-motion）
tests/                   # engine / storage / debrief / clock / unlock / settings / notifications / app 八套测试
scripts/verify-edge.mjs  # Edge headless + CDP 端到端验证
scripts/smoke-public.mjs # 公网地址冒烟测试（隧道/静态托管发布后跑）
```

**关卡数据位置**：`src/data/level01.ts`（节点、选项转移表、金额常量、消息与复盘标签）；状态转移逻辑在 `src/game/engine.ts`。新增节点需同时补充转移表、`NODE_OPTIONS`、复盘规则与测试。

## 已实现功能与测试结果

- **整页手机**：锁屏（上滑解锁）→ 桌面（状态栏、壁纸、图标）→ 青讯（会话列表 / 私聊 / 群聊 / 资料 / 返利 / 提现异常）→ 安心钱包 → 国家反诈中心 → 相册 → 手机内结局 → 手机内复盘，全程无外层网页、无第二层手机外框。
- **底部三大金刚键（2026-10-14 改版）**：底部由「桌面/返回/反诈」改为真机的**返回 / 主页 / 最近任务**三键。
  - 起因：桌面程序坞里已经有「国家反诈中心」，底部再来一个「反诈」等于同一个应用在一屏出现两个入口。
  - 三键始终可点（真机主页键不会变灰）；在桌面按主页/返回为空操作，不会把玩家带出游戏；消息应用内按返回逐层退：会话 → 会话列表 → 桌面。
  - **最近任务**做成真实可用的面板（列出打开过的应用，可切回；没有记录时显示空态），不是点了没反应的摆设。
  - 导航栏与状态栏**随页面明暗换色**：桌面深色、进入浅色应用后自动换浅色。
- **青讯改成真手机消息应用（2026-10-14 改版）**：
  - **会话列表**：头像 + 名称 + 最后一条消息摘要 + 时间 + 未读数字角标；**群聊用 2×2 拼图头像**、名称后带成员数（如「班级通知群（42）」），一眼与私聊区分；每行的无障碍标签写明「群聊：…」「私聊：…」。
  - **群聊与私聊的显示差异**：群聊在他人气泡上方显示发言人昵称与头像，私聊不显示（真机就是这样）；「谁说的」由消息行负责，气泡里不再重复渲染名字。
  - **生活费 800 元在会话里交代来源**：「妈妈」私聊里有一张**转账卡片**（¥800 · 生活费 · 已收款）和一句真实提醒（要你交钱才能做兼职的，一律别信），钱包收支记录首行对应改为「妈妈转来的生活费」。数值口径不变，只是把「钱从哪来」讲清楚。
  - 兼职群只有在玩家真的点了「进群看看」之后才出现在会话列表里 —— 进群是剧情里的明确选择，没进之前不该看到群里的话术。
- **相册不再空白（2026-10-14 新增）**：6 张**自绘 SVG 风景**（晚霞湖面 / 雪山 / 海边日落 / 城市夜景 / 校园银杏道 / 星空），按日期分组的 3 列缩略图，点开可全屏查看并左右翻页（`Esc` 关闭、方向键翻页）。
  - 为什么不用真实照片：真实照片有版权风险、体积大、还需要联网；矢量画放大不糊、离线可用，且断言里明确检查「没有引入任何外部图片」。
- **换页过渡动画**：解锁时桌面像被揭开一样放大淡入，应用之间切换轻微滑入；`prefers-reduced-motion` 下关闭。
  - 实现上刻意用纯 CSS 挂载动画而非 `<Transition mode="out-in">`：后者会等旧界面退场结束才挂载新界面，既拖慢操作，也会让自动化断言读到旧 DOM。
- **去除多余说明文字（沉浸感）**：锁屏删掉「这是一部虚构手机…」「给你 800 元虚拟生活费…」两段解释，只留一行「剧情演示 · 不涉及真实资金」；通知中心删掉「点击查看」（改为箭头）；结局页、复盘页、钱包待付款页的元叙述一并精简。付款确认页的模拟声明与「不用输卡号、验证码或密码」保留（合规要求）。
- **桌面模仿真实手机（2026-10-14 改版）**：
  - 图标**不套卡片**——此前每个图标外面套着一个带边框和半透明底的方框，看起来像设置项列表而不是桌面；现在图标裸浮在壁纸上（58px 圆角图标 + 下方 11px 小字标签，标签带细微投影保证在亮部也可读）。
  - 底部**程序坞（Dock）**：磨砂玻璃托盘（`backdrop-filter: blur(24px)`），放剧情最常用的三个应用（青讯 / 安心钱包 / 国家反诈中心）；其余三个（相册 / 通知 / 设置）在 4 列网格区。Dock 在滚动区之外固定，不随内容滚动。
  - **Widget 控件区**：左「时钟组件」（北京时间，与状态栏同一套时区规则）＋右「钱包组件」并排，下方是「继续当前事项」芯片；这是真手机桌面的典型排布，而不是把功能按钮平铺成列表。
  - **状态栏图形化**：右侧由文字「信号 · 78%」改为**自绘 SVG**（信号四格 / WiFi 弧 / 电池外框+电量填充）+ 百分比数字。
  - **壁纸**：多层光斑 + 星点 + 山峦剪影 + 地平线暖光，纯 CSS、无图片资源、无动画；留白区域也有内容，避免空桌面看起来像没加载完。
  - 角标仍是全项目唯一的数字徽标样式，位置改为压在图标右上角（真手机样式）。
  - 回归用例：`tests/app.spec.ts` 的 N01–N04（图标分布与去卡片、时钟组件、组件可点击），以及 `verify-edge.mjs` 的 3 条真实浏览器断言（图标尺寸统一含 Dock、图标无卡片底/无边框、Dock 存在且为磨砂、状态栏为图形图标）。
- **进入系统后延迟弹出通知**：解锁后先让玩家看清桌面，**3 秒后**才弹出第一条通知（`FIRST_NOTICE_DELAY_MS`），避免一进桌面就被横幅盖住。延迟只作用于本次进入系统的第一条，后续通知按队列正常接续。
- **锁屏上滑解锁**：整屏可上滑，拖过阈值即解锁；同时提供点击与键盘（Enter / 空格 / 上箭头）等效触发，不依赖手势；未达阈值回弹，尊重 `prefers-reduced-motion`。
- **顶部通知（两类统一风格，逐条弹出、定时关闭）**：从手机画面上方滑入的通知横幅——
  - **反诈预警**：盾牌图标 + 蓝色强调，标题「国家反诈中心提醒您」，进入关键节点触发，6 秒自动关闭。
  - **消息通知**：气泡图标 + 绿色强调，如学姐邀请、群消息，4 秒自动关闭。
  - **两类共用同一套视觉**：同一张白底卡片、同一套圆角/内距/阴影，**仅靠左侧强调色与图标区分类型**（早期版本预警深色、消息浅色，看起来像两套界面，已统一）。
  - 两类走同一队列**逐条**展示，互不覆盖；等待条数用 `+N` 角标提示；点关闭或超时后自动轮到下一条。
  - **解锁顺序**：先弹反诈预警，**学姐邀请排在预警之后**自动接上（不打断、不覆盖）。
  - **不遮挡**：进入通知中心/设置/复盘时清空展示队列，避免过期横幅压住页面标题。
  - 全部通知在通知中心按「国家反诈中心 / 消息」分组保留，条目样式与横幅同源（同底色 + 同强调色规则）；桌面「通知」图标带未读红点。
  - 提示音在通知**真正显示**时播放，因此排在后面的那条轮到时也会响。
- **单一通知入口**：状态栏点击与桌面「通知」图标进入**同一个**通知中心（早期版本的状态栏只读面板已移除，避免两个同名界面）。
- **反诈应用合并**：原「识骗手册」已并入**国家反诈中心**应用——桌面图标、应用标题、复盘入口、底部导航统一用它，不再出现两个反诈入口。应用内保留「识骗手册」作为栏目名。
  - 桌面六个模块：青讯 / 安心钱包 / 国家反诈中心 / 相册 / 通知 / 设置。
  - 图标风格统一：六个图标都是 **58×58、14px 圆角的彩色底板 + 白色图形**（青讯蓝 / 钱包绿 / 相册橙 / 通知黄 / 设置灰），与官方 logo 的呈现方式一致；反诈应用使用官方 logo 图片（自带蓝底金盾），不额外叠底板。图标样式集中在一个共用组件 `components/AppIcon.vue` 里，桌面网格、程序坞、最近任务面板共用同一份。
- **角标规则**：全项目只有**一种**角标样式——数字徽标（`.app__badge`，红底白字）。青讯显示待处理条数（或 `!` 表示有待确认付款），通知显示未读条数（>9 显示 `9+`）。
  - **时序一致**：角标必须等通知**真正弹出过**之后才出现（由通知队列的 `hasShownAny` 驱动），避免「横幅还在延迟、角标先亮」的倒置。进入通知中心即视为已读。
- **邀请提示采用「通知留存」**：桌面上不再放邀请卡片，改为**顶部通知 + 通知中心留存 + 「青讯」图标角标 + 「继续当前事项」入口**四条通路。通知中心里的消息条目可点击，直接进入会话。
  - 说明：`SCENES.md` 第 45 行原要求「桌面有显眼但不盖住所有图标的邀请通知」。按用户明确要求移除桌面卡片、改为通知留存；邀请仍可从图标角标、继续当前事项与通知中心三处进入，不会变成死路。
- **音效**：点击、消息、确认、取消、解锁、提醒各有独立提示音，用 Web Audio 实时合成，**不引入任何音频文件**；浏览器拒绝播放时静默降级，静音下可完整游玩。
- **设置**：真实的开关按钮（音效、顶部弹出通知），`role="switch"` 可键盘操作，写入版本化本地设置并立即生效；与剧情存档分开保存，重开本局不会重置偏好。「顶部弹出通知」是总开关：关闭后两类横幅都不再弹，但通知仍会记入通知中心。列表使用全项目共用的行样式；「本局」分组里提供**重新开始本局**（真机把「清空数据」放在设置里），与桌面入口共用同一套二次确认。
- **自由探索**：任一剧情阶段可回桌面、切钱包/手册/相册/通知/设置再返回；桌面有「继续当前事项」入口；结局与复盘可离开并从桌面或手册再次进入。

### 音效约定

| 场景 | 音效 |
| --- | --- |
| 导航、打开/关闭界面、普通按钮 | `tap` |
| 破坏性或丢弃类操作（清掉重来、清空） | `cancel` |
| 剧情里的确认付款 | `confirm` |
| 剧情里的拒绝/退出 | `cancel` |
| 通知弹出（预警 / 消息） | `alert` / `receive` |
| 解锁 | `unlock` |

原则：**玩家的每一次有意操作都要有反馈，但自动发生的事（通知到时自动关闭）不该补音效** —— 否则手动关闭与自动关闭会听起来一样，玩家分不清自己点没点上。
