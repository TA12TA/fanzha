# 反诈局中局：你的手机

面向大学生的竖屏 H5 反诈互动游戏。**产品形态：整个网页模拟一部可自由探索的虚构手机**；手机端直接铺满可见网页，开场、桌面、消息、钱包、结局及复盘都在手机内进行。玩家可以随时切换应用、查看余额和手册，再返回当前剧情，不强制困在对话中；电脑端居中预览同一画面。

当前状态：**第一关「刷单返利」可玩 MVP 已实现**（Vue 3 + Vite + TypeScript）。剧情引擎、整页手机界面、按经历复盘与版本化存档均已完成，单元/集成测试与真实浏览器验证全部通过。第二关、账号、后端、排行榜均未开发。

## 交给开发模型时怎么做

将此仓库作为其工作目录，直接给出以下指令：

> 阅读 `AGENTS.md`、`LEVEL-01.md`、`DEVELOPMENT.md`、`SCENES.md` 和 `ACCEPTANCE.md`，在仓库根目录实现 Vue 3 + Vite + TypeScript 可玩 H5。整个网页必须呈现为一部可操作的虚构手机：手机端铺满可见区域，先进入桌面，点通知/消息图标可进群，玩家也可随时切到钱包/手册/其他可用区域并返回当前剧情；离开待付款页只暂停、不自动扣款或取消，结局与复盘也在手机内可离开再进入；不要做成网页中嵌一个缩小手机模型或普通答题页。先完成全部分支与手机交互，再打磨视觉；完成后运行构建和可用测试，更新本 README 中的真实启动命令、已实现功能与已知限制，逐条报告验收情况。不要开发第二关或联机服务。

## 首版目标

一条完整、约 2–3 分钟的「刷单返利」剧情：虚构手机 → 兼职群 → 100 元模拟垫付 → 130 元平台展示返款 → 300 元解冻费诱导 → 不同结局 → 按玩家经历复盘 → 重开。所有金额仅为游戏模拟；不接支付、不收集个人信息。

## 命令与运行方式

```bash
npm install          # 安装依赖
npm run dev          # 本地开发（http://127.0.0.1:5173/）
npm run build        # 生产构建，输出 dist/
npm run preview      # 预览构建产物（http://127.0.0.1:4173/）
npm run typecheck    # vue-tsc 类型检查
npm test             # 单元 + 集成测试（vitest）
npm run verify       # 真实浏览器（Edge/Chrome headless）端到端验证，产出截图与报告
```

部署：`vite.config.ts` 使用 `base: './'` 相对路径，`dist/` 可直接放到任意静态目录（含子路径）。核心剧情不依赖任何外部服务。

## 工程结构

```text
src/
  app/AppShell.vue       # 全屏手机容器：状态栏 + 应用视口 + 底部导航 + 弹层
  app/navigation.ts      # UI 导航状态（应用/会话/待付款推导），不含剧情与金额
  app/clock.ts           # 北京时间时钟（固定 Asia/Shanghai，分钟对齐刷新）
  app/useGame.ts         # 组合式封装：dispatch 是唯一写入口，负责存档
  game/types.ts          # 节点、选项、状态、效果类型
  game/engine.ts         # choose() 事务式转移、不变式校验、结局视图
  game/debrief.ts        # 按 riskTags 生成复盘 + 肯定式误导表述检查
  game/storage.ts        # 版本化 localStorage，校验失败安全回退
  data/level01.ts        # 第一关节点、转移表、消息、话术标注、通用手册
  scenes/                # Intro / Home / Chat / Wallet / Manual / Ending / Review / PlainApp
  components/            # 状态栏、底部导航、应用标题栏、弹层、气泡、模拟声明
  styles/                # 设计令牌与基础样式（含 prefers-reduced-motion）
tests/                   # engine / storage / debrief / clock / app 五套测试
scripts/verify-edge.mjs  # Edge headless + CDP 端到端验证
```

**关卡数据位置**：`src/data/level01.ts`（节点、选项转移表、金额常量、消息与复盘标签）；状态转移逻辑在 `src/game/engine.ts`。新增节点需同时补充转移表、`NODE_OPTIONS`、复盘规则与测试。

## 已实现功能与测试结果

- **整页手机**：锁屏开场 → 桌面（状态栏、壁纸、图标、邀请通知）→ 青讯（邀请/群聊/资料/返利/提现异常）→ 安心钱包 → 识骗手册 → 手机内结局 → 手机内复盘，全程无外层网页、无第二层手机外框。
- **自由探索**：任一剧情阶段可回桌面、切钱包/手册/相册/通知/设置再返回；桌面有「继续当前事项」入口；结局与复盘可离开并从桌面或手册再次进入。
- **金额正确**：初始模拟余额 800 → 确认首次垫付 100 后 700 → 确认追加 300 后 400；平台展示 130 元仅作未兑现数字，始终不计入可支配余额。
- **防重复扣款**：确认按钮即时禁用 + 引擎一次性选项校验；连点、浏览器返回、旧按钮复现均不会二次扣款。浏览器返回键已接入游戏内历史：返回执行「回桌面」而不是离开游戏，也不撤销剧情。
- **按经历复盘**：只引用玩家实际遇到的环节（早拒绝者不会看到「解冻费」「追加」），结尾给出 2–3 条行动建议，明确不承诺追回。
- **存档**：版本化 localStorage，校验字段、金额不变式与历史-节点一致性；损坏/旧版存档自动清档回退开场；重开需二次确认并清除存档。
- **北京时间**：锁屏与状态栏显示真实北京时间（固定 `Asia/Shanghai` 时区格式化），设备处于任何时区都显示北京时间；每分钟对齐刷新，页面从后台恢复时立即校正。只读本地系统时钟，不发起网络请求。
- **无障碍与适配**：100dvh + `env(safe-area-inset-*)`，320px 无横向溢出，桌面居中限宽 430px，点击区 ≥44px，`prefers-reduced-motion` 时消息直出（已实测），重要操作全部为真实 `<button>`（已实测可键盘聚焦触发）。
